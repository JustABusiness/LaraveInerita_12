## 6. Service Layer Logic

```
paginate():
  → Lấy request filters
  → Gọi repository.paginate() với conditions
  → Trả PaginatedResult

save():
  → Validate (qua FormRequest)
  → prepareModelData()
  → Nếu có id: update, không có id: create
  → Trả success/error

destroy():
  → Kiểm tra record tồn tại
  → Soft delete
  → Trả success/error
```
